# 本地验证记录

验证日期：2026-10-14。环境：Python 3.12.14，jsonschema 4.26.0，Linux。
以下均使用虚构数据和临时 Registry / SQLite，不调用真实外卖、金融或模型接口。

2026-10-14 更名为 Splice 后，17 项测试与安装后的三个 CLI 演示再次通过。

## 安装与命令行

已在独立虚拟环境执行本地可编辑安装，并从仓库外目录运行安装后的 `splice demo combined --json`。当前环境已有依赖，安装使用 `--no-index --no-deps --no-build-isolation`；普通安装方式见 [README](../README.md)。

| 检查 | 实际结果 |
| --- | --- |
| `demo food` | 完成；清淡候选总价 24 / 28，排除含费 33 元项；保存 24 元 `draft` |
| `demo assets` | 完成；现金 4200，持仓估值 10500，总资产 14700；餐饮已花 960，预算剩 40 |

| 缺少草稿写权限、缺少金融权限 | 退出 2；拒绝，没有新增草稿 |
| 负数输入与不存在的插件 | 退出 2；分别为 ContractError、PlanningError |

三场景通过 CLI 独立运行；SQLite 草稿会持久化，资产数据保持不变。单插件 `invoke` 是契约实验入口，不自动附加跨域意图条件。

## 行为测试

```text
python -m unittest discover -s tests -v
Ran 17 tests
OK
```

覆盖：含配送费价格筛选、现金与估值区分、跨域结果绑定、Schema 拒绝、未知插件、未声明资源、金融与草稿权限、预算不足、现金不足、外卖跨领域越权、版本替换、新插件身份及事实发现、写入后输出错误回滚、草稿授权、独立网关价格核验、所有者过滤，以及 Adapter 伪造预算批准的拒绝。

测试中的低预算样本只剩 10 元，低现金样本只有 5 元但仍有 10500 元持仓估值，两者都不会生成草稿。金融记录不传给食品插件；跨域结果只向终端显示授权汇总。

## 证据边界

这验证受控模板、预先约定的事实词汇和数据契约下的有限组合。它没有验证真实 LLM 能力生产、未见领域的自然语言理解、真机性能、第三方插件来源认证、多笔预算预占或生产金融隐私保证。

下一阶段应先用真实模型评估未见契约的发现与填参，并记录新增能力需要的人工作业；领域 LoRA / Adapter 的研究在有此基线后进行。详细路线见 [roadmap](roadmap.md)。
